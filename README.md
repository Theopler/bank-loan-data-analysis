# bank-loan-data-analysis
Data analysis project on bank loan customers using Excel, SQL Power BI and tableau
## 🗂 Domain
Finance – Banking & Loans

## 📊 Datasets
- Finance_1.xlsx  
- Finance_2.xlsx  
- ~39,000+ records each  

## 🎯 Key KPIs Analyzed
- Year-wise loan amount statistics  
- Grade & sub-grade wise revolving balance  
- Total payment: Verified vs Non-Verified customers  
- State-wise loan status  
- Home ownership vs last payment date  
- Loan status vs last credit pull date  

## 🛠 Tools & Technologies
- Excel (Data Cleaning & Analysis)
- SQL (Querying & KPI generation)
- Power BI (Dashboard & Visualization)
- Tableau (Dashboard & Visualization)

- ## 🚀 Key Insights
- Verified customers show higher repayment reliability  
- Certain states contribute to higher default rates  
- Higher loan grades correlate with lower revolving balances
